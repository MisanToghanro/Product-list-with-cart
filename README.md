# Product-list-with-cart
A frontendmentor coding challenge
A responsive dessert product list application built with React and Tailwind CSS. Users can add items to the cart, adjust quantities, remove items, and confirm their order through a modal interface.

## Features

- Display products dynamically from a local JSON file
- Add and remove items from the cart
- Increase and decrease product quantity
- Dynamic cart total calculation
- Order confirmation modal
- Reset cart with “Start New Order”
- Responsive layout for mobile and desktop
- Hover and focus states for interactive elements

## Built With

- React
- JavaScript
- Tailwind CSS
- Vite
